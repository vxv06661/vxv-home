第二人生：ELSE 隐私政策

更新日期：2026 年 10 月 20 日；生效日期：2026 年 10 月 20 日。

第二人生 / ELSE（以下简称“ELSE”或“本应用”）是一款面向成年人的 AI 小说创作工具。本政策说明创建账号、人物和故事世界、生成剧情、使用本地图片和书架、自带 API、购买服务及注销时的信息处理方式。

个人信息处理者为16Verse，产品品牌为 16Verse。联系邮箱：vxvstudio@vc0871.top。

请先了解三个边界：

- 完整作品存档主要保存在本机，不等于生成请求完全不联网。 使用 AI 时，必要输入和上下文会发送给对应模型服务。 - 平台模型与自带 API 的接收方不同。 平台调用经 ELSE 后端转发；自带 API 直接请求您配置的地址，但账号和权益校验仍连接 ELSE。 - 目前没有完整世界云同步。 卸载、清除数据或设备损坏可能造成无法恢复；账号、订阅和余额同步不能恢复已经丢失的本地作品。

本政策不把虚构角色资料当然视为您的真实个人信息，也不会因资料写在小说中就认定其中真实自然人的个人信息可以任意处理。请尽量使用虚构或去除可识别细节的素材，不输入与创作无关的真实敏感信息。

一、信息处理清单

1. Apple 登录与账号资料

在您主动使用 Apple 登录时，我们处理 Apple 用户标识、登录所需的身份凭证与授权码，以及您授权提供的姓名和邮箱；使用隐藏邮箱时可能取得 Apple 转送邮箱。还处理 ELSE 账号 ID、昵称、注册及登录时间、会话状态和必要的账号安全版本信息，用于建立账号、验证身份、维持登录、更新资料、防滥用与注销核验。

登录令牌保存在本机系统安全存储；服务器保留提供账号服务所需的资料。我们不索取 Apple 账户密码、设备解锁密码或面容识别原始数据。系统用于 Apple 登录的身份验证由 Apple 处理。

2. 订阅、钱包、试用与名额

为验证购买、提供和恢复权益、避免重复发放及处理退款，我们处理商品和交易标识、订单验证信息、订阅档位与有效期、续订/取消/退款/撤销等状态、试用正式回合与其他必要用量计数、订阅额度、永久补充币余额及变动、时间静止卡余额与使用记录，以及世界/宇宙名额相关 ID、状态和请求编号。

平台模型计量还可能记录操作类型和编号、世界或回合 ID、分支版本、模型名称、输入/输出及缓存命中用量、扣费金额、错误码与完成时间等。上述记录用于计量、幂等和账务核对，不等于在服务器保存完整作品。

Apple 直接处理您的付款方式、银行卡等支付账户信息；我们接收提供服务所需的购买验证数据，不取得您的银行卡完整信息或 Apple 密码。

3. 小说设定、创作内容与长期记忆

您主动提供的问卷答案、人物设定、虚构身份、世界和场景、写作指令、角色对白及生成正文，以及剧情派生的关系印象、地点、事件、时间、人物状态、账本和记忆摘要，会用于保存、继续和整理作品。完整存档按账号保存在本机。

当您发起开场、续写、人物/场景/记忆整理、离开世界后的叙事结算等 AI 操作时，会选取完成该请求所需的设定、输入、既有剧情与派生摘要组成模型上下文。是否发送某段内容取决于具体请求和上下文，不仅限于您刚输入的最后一句话。

问卷与角色关系用于创作设定，不用于认定您的真实人格、疾病、信用或其他现实身份，也不应作为向您实施差别定价或广告画像的依据。

4. 头像、世界图片、快照、人物与地点相册、封面及预设壁纸

您主动选择图片时，应用在系统授权范围内提供相册浏览与选择，读取相应图片、缩略图和必要文件信息，并根据具体功能在本机进行裁剪、缩放、压缩、主色分析和保存。头像一般选择单张，人物与地点相册可选择多张。

人物和地点图片按当前账号、世界及对应人物或地点关联保存在本机，用于相应卡片和相册展示。它们不因添加到人物或地点卡片而自动提交给模型进行识图。

预设壁纸随应用提供，浏览和选用这些内置图片不需要读取您的系统相册。选用状态及与世界背景的关联保存在本机；使用您自己的图片时，适用本节的图片选择和保存规则。

图片文件以及用于显示和恢复的清单、文件名、首图/当前背景选择和必要创建时间等保存在本机账号对应目录；它们不作为头像云同步或世界图片云存档上传 ELSE 后端。当前这些本地图片功能不把图片提交给模型进行识图，也不进行用于身份识别的人脸识别。 图片元数据由您选定的原文件、图片处理组件和系统共同决定；不承诺所有原始图片都已去除全部元数据。

图库浏览在系统授权范围内进行，不应表述为获得了全部相册权限却只可能访问一张照片。您可通过系统的有限照片访问等选项控制授权范围。拒绝相册权限不影响不依赖图片的文字创作功能。

5. 导入、书架与导出

导入 TXT、EPUB 时，应用通过系统文件选择器读取您主动选定的文件，在本机解析文字并分章。当前不因导入就上传原文件或全文给 ELSE 后端及模型，也不自动扫描其他文档。EPUB 文字解析不自动加载书中的外部网络资源。

应用保存书名、简介、来源文件名、章节原文及编辑后的正文、归档来源范围、阅读位置、书签和您选择的封面。当前章节归档读取既有剧情，不因点击归档就另行向模型发送整本小说。若您主动将某段内容另行用于 AI 请求，适用对应的请求规则。

导入可能由系统或文件选择组件生成临时副本；删除应用内书籍不会自动删除源文件。应用会按实际能力清理其管理的临时文件，其余受系统机制控制。

导出时，在本机生成普通文本文件并调用系统分享面板；导出文本不属于加密存档。您选择分享目标后，相应系统或第三方应用按其规则处理。应用内删除、注销不能撤回已保存或发送到应用外的副本。

6. 用户自带 API 配置

所有已登录用户均可填写、校验并保存接口格式、HTTPS 地址、API Key、剧情与整理模型名称等配置；实际使用自带 API 进行作品生成、整理及离开结算等创作操作，需要有效的 API 订阅。配置保存或校验通过不会自动开通订阅，也不会自动切换当前创作方式。

API Key、相关配置及所属账号信息保存在本机系统安全存储。API Key 不上传 ELSE 后端，但在连接校验和实际模型请求中，会按所选协议作为认证信息发送给您配置的模型接口或中转地址。

连接校验会使用应用构造的虚构测试内容及相应提示词，检查开场、剧情、人物记忆、账本、场景和离开结算等生成环节，不读取您的真实世界存档作为校验素材。校验包含多次模型请求，必要的重试可能增加请求次数；即使您尚未订阅 API 会员，也可能产生由相应服务商结算的调用费用，不扣除 ELSE 平台补充币。校验通过仅表示当次测试满足相应要求，不保证第三方接口此后始终可用。

模型请求直接由设备发送至该地址。接口服务商或中转可能接收您的输入、设定、历史剧情和整理摘要等上下文，以及其处理网络连接所必需的信息。ELSE 无法通过本地清除操作删除其已经接收的内容。

自带 API 的模型正文不经 ELSE 后端转发；但登录、订阅/世界权限验证、名额管理等仍与 ELSE 通信，可能包含账号、世界 ID 和操作类型等，不包含 API Key。切换为平台模型使用永久补充币前，应按相应流程取得您的明确选择，并按平台调用路径处理后续生成内容。

7. 网络运行、安全与客服

使用网络功能时，服务器、网关与基础设施可能处理 IP 地址、请求时间、路径或接口类型、响应状态、必要的设备/应用协议参数及异常信息，用于连接、安全防护、排障和账务核查；不将其概括用于无限制广告营销。

您主动通过邮箱提出请求时，我们处理所提供的联系方式、问题描述和必要的核验信息。请勿发送 API Key、Apple 密码、完整敏感收据或无关的整本私人小说。非必要的身份证件、完整银行卡或联系人名单不应作为一般客服请求的前提。

当前没有因小说创作而读取通讯录、短信、通话记录、精准定位或日历的业务需求，也不因文字创作默认申请相机、麦克风或通知权限。新增功能需要这些权限或新增信息用途时，应另行说明。

二、两种模型调用路径与结果暂存

1. 平台模型

免费体验、普通订阅，以及 API 用户或订阅到期用户明确选择消耗永久补充币的相应平台操作，将必要上下文经加密连接发送 ELSE 后端，由后端调用平台实际采用的模型服务商。当前平台模式使用 DeepSeek 模型服务；接收方及政策见第三方清单。

完整世界不作为云端档案整体同步，但为断线后恢复同一次请求、防止重复生成和扣费，已经生成的结果会在 ELSE 服务端短期暂存，可能包含剧情正文或摘要。临时结果的默认恢复窗口为 72 小时，超过恢复窗口不再提供同次结果回放，并由到期清理任务删除正文。清理异常时应进行补偿处理，不将其转为长期作品存储。

请求编号、计量、交易及防重复记录可按必要期限保留；这些账务记录的保留不能被扩张解释为可长期保存完整作品。若备份中暂时无法单独删除相应信息，应限制除存储和必要安全保护之外的处理，并在备份轮换时删除或匿名化，不将备份重新用于无关目的。

2. 自带 API

生成正文直接请求您配置的第三方地址，适用其处理规则。您选择的接口可能由中转运营方提供，也可能将数据继续转给其他模型厂商；不能仅根据模型名称判断接收方或保存地点。

账号与权益的服务端校验不等于 ELSE 后端处理了该次模型正文；反之，“设备直连”也不意味着内容仅在手机里处理。

3. 模型训练与其他用途

ELSE 不因您接受本政策就取得把作品公开发布、出售或用于训练 ELSE 自有模型的概括授权。若拟新增训练、公开展示等用途，应另行明确目的、范围和法律依据，依法取得所需同意；拒绝非必要用途不应影响无关功能。

模型厂商的数据留存、服务优化和训练规则取决于其适用政策及与运营方的有效约定。本政策不替第三方承诺“零留存”或“绝不训练”。 ELSE 应依法通过有效约定限定平台服务商的处理范围；自带 API 请核对您具体服务商的约定。若相关接收方或用途发生实质变化，我们应依法另行告知并取得所需同意。

三、处理依据、委托与共享

1. 对账号建立、您主动请求的生成与购买履行所必要的信息，我们在相应合法基础上处理；系统权限及其他基于同意的事项由您自主决定。需要单独同意、书面同意或其他法定条件的，不能仅依赖本政策的一次同意。 2. 委托服务商处理信息时，应明确目的、期限、范围、安全要求与删除安排并依法监督；向独立个人信息处理者提供信息时，应履行接收方告知及所需单独同意义务。具体法律角色取决于真实合同及处理安排，不能只在文本中把所有第三方称为“受托人”。 3. 我们不出售您的个人信息，不默认公开私人作品，不向无关第三方提供创作内容。依法履行法定义务、处置安全事件等情形，按必要范围处理和披露。 4. 发生合并、分立等涉及信息转移的情形，应依法告知接收方身份与联系方式，并要求其履行相应保护义务；目的或方式改变时依法重新取得同意。 5. 不应主动输入真实医疗健康、金融账户、行踪等敏感信息。确需处理敏感个人信息时，应说明必要性和影响并依法单独取得同意；“用户自己打进输入框”不能概括替代应履行的保护义务。

5. 本地功能组件与分享目标

当前代码使用系统/Flutter 组件完成本地安全存储、相册选择、裁剪、压缩、文件导入与分享。这些组件的存在不意味着我们已经把图片或小说交给其开发者服务器；不能把全部依赖包一律写成数据接收方。完整第三方组件及实际收集行为须以发布构建和网络验证为准。

您主动选择的系统分享目标，按其自身规则接收导出的内容；应用不能代替您撤回这些外部副本。若未来加入统计、广告或崩溃收集 SDK，应先更新清单并依法告知。

五、本地保存、服务器保存

1. 世界、剧情、记忆和书架等核心本地数据库按账号隔离并加密，密钥使用系统安全存储；图片文件、清单和导出文本位于应用沙盒，并不因此都具有数据库加密保护。普通显示设置及必要缓存另在本地保存。 2. 普通退出登录通常保留账号在当前设备上的作品和图片；删除相关内容或注销后，应用按相应范围清理。其他设备副本、系统备份、原始导入文件及已分享文件需分别管理。系统安全存储中数据的生存期受操作系统机制影响，不承诺卸载后所有系统凭证必然同步删除。 3. 账号、权益及临时结果由提供相应功能的服务器和基础设施保存；模型服务及 Apple 服务按其适用规则处理。自带 API 的实际接收方及保存地点取决于您配置的接口。我们不以“本地存档”概括承诺所有网络处理均在手机内，也不将第三方处理地点等同于 ELSE 服务器所在地。

六、保存期限与删除安排

1. 本机作品、记忆、书架、图片与清单：通常保存至您删除相应内容、注销并完成本机清理、清除应用数据或卸载；原始文件、外部副本及系统备份另行管理。

2. 会话与账号资料：按提供账号和安全服务所必要期间保存。注销后撤销会话，删除或匿名化无需继续保留的资料；依法确需保留的信息限定用途并采取保护措施。

3. 平台生成结果正文：默认临时恢复窗口为 72 小时，超过窗口按到期清理机制删除；该期限不是完整作品的云备份期限。清理异常应补偿处理；依法暂不能单独删除的备份信息限制用途并随轮换清理。
